Task: AI assisted code review system

Frontend: React.js
Backend: Python Flask
AI Integration: LM Studio (http://127.0.0.1:1234)
Packaging: README with setup and run instructions
Dockerization: docker-compose for both frontend and backend

UI:
1. Landing Page: Allow users to upload code files (drag and drop, and upload zip) for review.
2. On submission, upload the archive to the server. 
3. Should contain a file browser to navigate through the uploaded files on the left panel.
4. Allow the user to select a file from the browser and view its contents on the right panel.
5. Display the code with syntax highlighting.
6. Should contain a "Run an AI Review" button to trigger the AI review process.
7. Show code review comments and suggestions in a separate panel adjacent to the code.
8. Should be resposive.
